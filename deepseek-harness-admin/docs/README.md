# Harness 管理平台文档

## 1. 项目简介

当前仓库 `deepseek-harness-admin` 是面向管理员的后端管理项目，用于维护全局共享的知识库、Skills 和数字员工，并发布数字员工。它不是普通用户使用数字员工的客户端或运行时项目。

普通用户侧仅允许使用已发布的数字员工；对应的运行或对话入口由独立的用户端或运行时提供，不属于当前管理后台的主要功能范围。

管理端在**数字员工预览页**提供管理员专用的对话验证能力：管理员可在发布前或发布后与该数字员工进行实时对话，检查其回复是否满足预期。该能力仅用于管理验证用途，不替代普通用户端正式对话服务（管理后台边界见 [ARCHITECTURE.md](./ARCHITECTURE.md) 第 8 章）。

## 2. 功能范围

### 2.1 主要功能

1. 上传知识库
2. 添加 Skills
3. 添加数字员工
4. 发布数字员工
5. 管理端预览对话（数字员工实时对话验证）

### 2.2 管理后台辅助功能

1. 管理员登录和退出登录
2. 管理员账号注册或初始化
3. 查看共享知识库
4. 查看共享 Skills
5. 查看数字员工和发布状态
6. 在预览页与数字员工实时对话（管理验证用途）
