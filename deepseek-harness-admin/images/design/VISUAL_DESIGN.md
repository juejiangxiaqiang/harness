# 管理端前端视觉设计方案

> 适用范围：deepseek-harness-admin 管理后台（管理员侧）
> 参考依据：`images/reference/` 下两张参考图（数字员工工作台 / 能力中心页面）
> 说明：本方案仅提供视觉与交互设计描述，不包含代码实现。

---

## 1. 设计目标与总体定位

管理后台面向**管理员**，核心任务是管理全局共享的知识库、Skills、数字员工并发布版本。页面风格需传达：**专业、可信赖、克制、效率优先**。

参考图提炼出的核心风格特征：

| 特征 | 参考图体现 |
|---|---|
| 布局 | 左侧固定侧边栏 + 右侧主内容区（T 型布局） |
| 主色调 | 蓝紫系（#5B6BF5 附近）为品牌强调色，克制使用 |
| 中性色轴 | 浅灰背景 + 白色卡片 + 灰阶文字构建层级 |
| 字体 | 系统无衬线栈，字号梯度 24→16→14→12，字重 600/500/400 |
| 组件 | 胶囊圆角按钮、圆形文字图标（渐变底+白字）、细边框卡片、胶囊式切换、下划线分类标签 |
| 交互 | 导航选中态（浅蓝底+左侧色条）、hover 微反馈、骨架/空态兜底 |

**三大设计原则：**
1. **信息层级优先**：通过 字号对比 + 字重对比 + 颜色对比 三层手段区分主次，不做装饰性过度设计。
2. **色彩克制**：品牌蓝紫仅用于激活态、主按钮、图标与链接，避免大面积铺色。
3. **一致性**：全站复用统一的设计令牌（色彩、间距、圆角、阴影），页面差异只体现在内容结构上。

## 2. 设计令牌（Design Tokens）

以下令牌为全站唯一来源，所有页面和组件必须引用，不得散落魔法值。

### 2.1 色彩体系

| 令牌名 | 色值 | 用途 |
|---|---|---|
| `primary` | `#5B6BF5` | 品牌主色：主按钮、激活标签、链接、进度强调 |
| `primary-hover` | `#4A58E0` | 主色 hover 加深 |
| `primary-bg` | `#EBF2FC` | 导航选中背景、标签选中背景（浅蓝） |
| `accent-blue` | `#4A90E2` | 图标高亮、信息类辅助（参考图一主蓝） |
| `accent-purple` | `#8B7BFF` | 模块图标辅助色（参考图一"我的收藏"） |
| `accent-teal` | `#5CD7A8` | 成功/完成类辅助色（参考图一"最近使用"） |
| `bg-page` | `#F5F6F8` | 页面底层背景 |
| `bg-surface` | `#FFFFFF` | 卡片、侧边栏、弹窗、表单表面 |
| `text-main` | `#1F2329` | 主标题、正文重要信息 |
| `text-secondary` | `#8F959E` | 描述文本、次要信息 |
| `text-placeholder` | `#BFBFBF` | 占位符、时间戳、弱化标签 |
| `border-default` | `#DEE0E3` | 卡片边框、输入框边框、分割线 |

| `warning-bg` | `#FFF8E6` | 警示标签底色 |
| `danger` | `#F5222D` | 失败态（FAILED）、删除、校验错误 |
| `danger-bg` | `#FFF1F0` | 失败标签底色 |
| `info` | `#1890FF` | 处理中状态（PROCESSING） |
| `info-bg` | `#EAF4FF` | 处理中标签底色 |

### 2.2 字体体系

| 属性 | 取值 |
|---|---|
| 字体栈 | `-apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif` |
| 页面标题 | 24px / 600（页面首屏大标题可 28px） |
| 模块/卡片标题 | 16px / 500 |
| 正文/表单 label | 14px / 400 |
| 辅助文字/标签/面包屑 | 12px / 400 |
| 行高 | 标题 1.4，正文 1.5 |
| 数字/代码 | 等宽退化到系统默认，不引入额外字体 |

### 2.3 间距与圆角

- **间距基数 8px**：8 / 12 / 16 / 20 / 24 / 32 / 48。
- **圆角**：
  - 按钮（含胶囊切换）：`9999px`（胶囊）
  - 输入框、标签、卡片角标：`6px`
  - 卡片容器：`12px`
  - 弹窗：`16px`
- **阴影（三层克制体系）**：
  - `shadow-sm`：`0 1px 2px rgba(0,0,0,0.04)` —— 输入框、普通卡片
  - `shadow-card`：`0 2px 8px rgba(0,0,0,0.06)` —— 悬浮卡片、下拉面板
  - `shadow-modal`：`0 8px 24px rgba(0,0,0,0.12)` —— 弹窗、抽屉

### 2.4 图标与图形风格

- **导航/功能图标**：线性描边风格，2px 描边、圆角端点，16-18px。
- **业务图形图标**：圆形容器（40-48px）+ 渐变背景 + 白色首字（如"知""技""员"），渐变配色在品牌蓝紫/青绿之间取色区分业务域。
- **装饰图形**：品牌区与空状态使用柔和渐变 + 高光的 3D 拟物小图形（参考图一卡片头部风格），仅用于点缀，不遮挡信息。

## 3. 全局框架（App Shell）

除登录页外，其余 4 个页面共用同一套外壳。

### 3.1 布局结构

```
┌────────────┬──────────────────────────────────────────────┐
│ 侧边栏      │ 面包屑：Harness 管理后台 > 资源管理 > 知识库      │
│ 220px 固定  ├──────────────────────────────────────────────┤
│            │ 页面标题区（标题 + 副标题 + 右侧操作按钮/搜索）    │
│ 品牌区      ├──────────────────────────────────────────────┤
│ 菜单分组    │                                              │
│ 分隔线      │              内容主体区（自适应宽度）            │
│ 用户区      │                                              │
└────────────┴──────────────────────────────────────────────┘
```

### 3.2 侧边栏

- 宽度 220px，白色背景 `bg-surface`，右侧 1px 边框 `border-default`。
- **品牌区**：几何三角形 Logo（主色渐变）+ 名称"Harness 管理后台"（16px/500）+ 副标签"数字员工"（12px，`text-placeholder`）。
- **菜单分组**：
  - 资源管理：知识库、Skills、数字员工
  - 分隔线后独立组：发布管理（可含"管理驾驶舱"入口）
- **选中态**：背景 `primary-bg`（#EBF2FC）+ 左侧 3px 蓝色指示条 + 图标与文字 `primary`；默认态灰图标灰文字（`text-secondary`）；hover 态背景 `#F0F2F5`。
- **底部用户区**：圆形头像（渐变底白字首字母）+ 管理员姓名 + 退出按钮（hover 变 `danger`）。

### 3.3 顶部内容区

- **面包屑**：12px，`text-secondary`，当前页高亮 `text-main`，分隔符 `/`。
- **页面标题区**：左 24px/600 标题 + 12px 副标题说明；右侧放高频操作按钮（如"上传知识库"）与全局搜索框。
- **搜索框**：线框输入框 + 放大镜图标，聚焦时边框 `primary` + 轻阴影。

## 4. 五个核心页面设计

### 4.1 登录页面

**页面目标**：账号密码登录，管理员身份认证，无其他功能干扰。

**布局结构（左右分栏）**：

```
┌──────────────────────────────────────────────┬────────────────────────┐
│  品牌展示区（60%）                            │  登录表单区（40%）       │
│                                              │                        │
│   [渐变几何 Logo]                            │   欢迎回来               │
│   Harness 管理后台                           │   请登录管理员账号        │
│   副标语：统一管理知识库 / Skills / 数字员工  │                        │
│                                              │   账号 [输入框]          │
│   [3D 装饰图形组：蓝色渐变卡片 + 数据流动线]    │   密码 [输入框(眼睛切换)] │
│                                              │   [√] 记住我   忘记密码  │
│   背景：主色向浅蓝的柔和渐变                   │                        │
│                                              │   [登录按钮（全宽主按钮）] │
│                                              │                        │
│                                              │   [错误提示内联/Toast]   │
│                                              │   版权行  © 2026        │
└──────────────────────────────────────────────┴────────────────────────┘
```

**色彩搭配**：
- 左区：渐变背景（`#5B6BF5` → `#4A90E2`，或向下渐隐至 `#EBF2FC`），白色品牌文案。
- 右区：纯白表面卡片，`border-default` 1px 边框 + `shadow-card`，卡片内宽约 380px。
- 输入框：白底线框；错误态边框 `danger`、底色 `danger-bg`。
- 主按钮：`primary` 填充、白色文字，hover `primary-hover`，disabled 灰底 `#F5F5F5`。

**字体选择**：
- 左侧品牌名 24px/600 白色；副标语 14px 白色 85% 透明。
- 右侧"欢迎回来" 28px/600 `text-main`；说明 14px `text-secondary`；表单 label 14px `text-main`。

**交互元素样式**：
- 密码框右侧"显示/隐藏"眼睛图标切换（hover 变 `primary`）。
- "记住我"为自定义复选框：未选中空心方框，选中 `primary` 底 + 白色对勾。
- 登录按钮加载态：按钮内菊花 loading + 文案"登录中…"，防重复提交。
- 登录失败：输入框下方内联红字提示（如"账号或密码错误"），不清空密码以外的表单。
- 聚焦态：输入框 1px `primary` 边框 + 2px `primary` 25% 透明度外发光。

**页面目标**：上传文档 → 触发解析/切分/向量化任务 → 查看任务状态与列表。

**布局结构（列表页 + 上传弹窗）**：

```

│ [全部 | 待处理 | 处理中 | 已就绪 | 失败]  ← 胶囊式状态筛选           │
├──────────────────────────────────────────────────────────────────┤
│  ┌──────────────┬──────────┬──────┬────────────┬───────────────┐  │
│  │ 名称          │ 文件类型  │ 大小  │ 状态        │ 操作           │  │

**上传弹窗（Dialog）**：

```
┌──────────────────────────────────────────────┐
│ 上传知识库                            [×]      │
├──────────────────────────────────────────────┤
│  ┌────────────────────────────────────────┐  │

│  └────────────────────────────────────────┘  │
│  文件列表：                                  │
│  ├ 产品手册 v2.pdf  8.2M  [上传中…] [移除]   │
│  ├ 合规制度库.docx  2.1M  [√ 已上传] [移除]  │
│  ── 上传完成后自动开始解析、切分、向量化 ──   │
│                              [取消] [开始上传]│
└──────────────────────────────────────────────┘
```

**色彩搭配**：
- 页面背景 `bg-page`；表格为白色卡片（`bg-surface` + 1px `border-default` + `shadow-sm`），表头背景 `#FAFBFC`。
- 状态标签配色：
  - `UPLOADING`：灰底灰字（`#F5F5F5` / `text-secondary`）
  - `PROCESSING`：蓝底蓝字（`info-bg` / `info`），左侧 8px 旋转小菊花
  - `READY`：绿底绿字（`success-bg` / `success`）
  - `FAILED`：红底红字（`danger-bg` / `danger`），hover 显示失败原因 Tooltip
- 上传拖拽区：2px 虚线边框 `border-default`，拖拽悬停时变 `primary` 虚线 + `primary-bg` 底。
- 主按钮"+ 上传知识库"：`primary` 胶囊按钮，白色加号图标。

**字体选择**：
- 页面标题 24px/600；副标题 12px `text-secondary`。
- 表格：名称列 14px/500 `text-main`；类型/大小/时间列 12px `text-secondary`。
- 状态标签 12px/400。

**交互元素样式**：
- 状态筛选为胶囊标签组：激活态 `text-main` 深色填充（参考图二"专家/专家团"），默认态白色线框；hover 边框 `primary`。
- "重新向量化/重新处理"：文字链接 12px `primary`，hover 加深加下划线；需二次确认弹窗（提示将清理旧向量后重建）。
- "删除"：文字链接 `text-secondary`，hover 变 `danger`；点击弹确认框（红字警示"删除后不可恢复"）。
- PROCESSING 行进度：状态标签旁显示进度百分比 + 细进度条（`primary` 填充）。
- 空状态：居中 3D 装饰图形 + "暂无知识库" 14px `text-secondary` + "去上传"主按钮。
- 加载态：表格骨架屏（灰条 shimmer），不闪白屏。

### 4.3 创建 Skills 页面

**页面目标**：填写 Skill 名称/描述/内容配置，并选择一个或多个 `READY` 状态知识库（多对多）。

**布局结构（左侧表单 + 右侧选择面板，内容区 60/40 分栏）**：

```

│ 面包屑：Harness 管理后台 > 资源管理 > Skills > 新建 Skill           │
├──────────────────────────────────────────────────────────────────┤
│ 创建 Skill                                                        │
├──────────────────────────────┬───────────────────────────────────┤
│ 表单区（60%）                 │ 关联知识库面板（40%，卡片）          │
│ 名称  [输入框]               │ ┌─────────────────────────────┐   │
│ 描述  [多行文本域]           │ │ 关联知识库        [搜索框]   │   │

│                              │ │ (灰色不可选: PROCESSING/    │   │
│ 校验提示：                     │ │  FAILED 状态禁用+原因提示)   │   │

**色彩搭配**：
- 左表单：白色表面卡片，label 14px `text-main`（必填项前缀红色 `*`），输入框白底线框。
- 右面板：白色卡片，标题 16px/500 + 已选计数角标（`primary` 胶囊小标签）。
- 知识库条目：左圆形文字图标（渐变底白字，如"产""合""授"）+ 名称 14px/500 + 状态小标签；勾选框 `primary`。
- 禁用条目：整体 60% 透明度，状态位显示灰色禁用标签 + Tooltip"仅 READY 状态知识库可关联"。
- 文本域错误：边框 `danger` + 下方 12px 红字校验信息。

**字体选择**：与全局令牌一致；右侧"已选 n/8"为 12px `primary`。

**交互元素样式**：
- 知识库选择采用卡片复选（点击整行切换勾选），hover 行背景 `#F5F6F8`。
- 右侧面板顶部搜索框对列表做本地模糊过滤。
- 保存校验：失焦即校验（blur 校验），提交时全量校验；失败滚动定位到首个错误字段并高亮。
- "保存草稿"次按钮（白底线框胶囊）与"保存"主按钮（`primary` 胶囊）并列。
- 顶部/底部提供"上一步/下一步"式引导可选，但默认单页表单，不做分步向导。

## 5. 全局交互与状态规范

| 状态 | 规范 |
|---|---|
| Hover | 可点元素均需 hover 反馈：按钮加深/加边框、卡片 1px 边框变 `primary` + `shadow-card` 上浮、文字链接下划线 |
| Active | 点击瞬间轻微下沉（translateY(1px)）或背景加深 |
| Focus | 输入类控件 1px `primary` 边框 + 2px 25% 透明度外发光 |
| Disabled | 统一 50% 透明度 + `not-allowed` 光标，不单独换色系 |
| Loading | 按钮内 loading；列表/卡片用骨架屏（灰条 shimmer，1s 循环） |
| Empty | 3D 装饰图形 + 说明文案 + 引导按钮 |
| Error | 表单内联红字；全局操作用 Toast（右上角，3s 自动消失，error 类型红边） |
| 成功反馈 | Toast 成功类型，绿色对勾图标 |

**通用反馈优先级**：表单内联错误 > 操作结果 Toast > 二次确认弹窗。

## 6. 响应式与无障碍约束

- 内容区断点：≥1440px 内容最大宽 1320px 居中；1200-1440 保持 4 列卡片；768-1200 减至 2-3 列；<768 侧边栏收起为抽屉图标栏。
- 对比度：正文与背景 ≥ 4.5:1（`#1F2329` 与白底、`#8F959E` 仅用于 14px 以上次要文字）；状态标签文字不使用浅色文字+浅色底组合。
- 键盘可达：所有按钮、菜单、复选项支持 Tab 聚焦并有可见焦点环（`primary` 2px 虚线）。
- 动效：过渡统一 0.2s ease；`prefers-reduced-motion` 下关闭呼吸/跳动动画。
